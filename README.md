# 🔐 Message Encryption and Decryption Using JavaScript

 About the Project

This is a simple JavaScript-based project developed to explore the fundamental concepts of encryption and decryption.

The idea behind this project came from my interest in understanding how JavaScript can be used to solve practical problems. While learning JavaScript, I became interested in cybersecurity and wanted to build something that connects programming with information security.

This project allows users to encrypt messages and decrypt previously encrypted messages using a key.

It is a beginner-level project created as part of my journey into JavaScript programming and cybersecurity.

 Project Objectives

- Understand the basic concepts of encryption and decryption.
- Explore how encryption keys are used to protect information.
- Apply JavaScript programming skills to a practical problem.
- Develop an understanding of confidentiality, one of the fundamental principles of cybersecurity.
- Build a foundation for exploring more advanced cryptographic concepts.

 Features

- **Message Encryption:** Convert readable messages into encrypted text.
- **Message Decryption:** Recover the original message using the appropriate key.
- **Key-Based Operations:** Use a key to control the encryption and decryption process.
- **JavaScript Implementation:** Apply JavaScript concepts to implement the functionality.

 Technologies Used

- HTML
- CSS
- JavaScript

 How It Works

The application follows a simple process:

1. The user enters a message.
2. The user provides an encryption key.
3. The application encrypts the original message.
4. The encrypted message is displayed.
5. To recover the original message, the user enters the encrypted text and the correct key.
6. The application decrypts the message and displays the original content.
